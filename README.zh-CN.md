# CEO TERMINAL — World

[English](./README.md) | **简体中文**

**一款围绕真实 B2B 销售、判断、人际关系、公司生存与长期后果展开的像素风商业 RPG。**

> **没有事实，就没有进展。**

CEO TERMINAL 不是 CRM，也不是“点按钮刷进度”的销售小游戏。

玩家进入一个持续变化的商业世界，在公司、客户单位和社会场景中移动，与不同人物交流，获取不完整信息，分配时间 / 人员 / 现金，做出判断，让时间推进，并承担决策产生的后果。

**探索 → 交流 → 获取信息 → 判断 → 配置资源 → 行动 → 时间推进 → 世界反馈**

一个态度友好的客户未必拥有决策权；一个普通员工几年后可能成为关键人物；大合同也可能带来现金流和交付危机；同行有时是竞争者，有时也可能成为合作方。收入不等于现金，口头支持也不等于组织承诺。

---

## 底层哲学

**世界按照客观规则运行；人物按照自身认知、立场与利益行动；玩家只能基于有限且可能不完整的信息作出决策；结果由事实、规则与因果关系决定，而不是由玩家的愿望决定。**

**结果必须合理，但不必符合玩家的预期。**

这就是 CEO TERMINAL 所说的 **“没有事实，就没有进展”**。动作不等于进展，意愿不等于承诺，推测不等于事实。只有可以被验证的真实变化，才能改变世界状态。

一个合理的判断也可能短期失败；一个错误判断也可能因为偶然因素暂时奏效。系统不承诺给玩家想要的结果，只要求重要结果能够被事实与因果关系解释。

在具体销售系统中，“没有事实，就没有进度”仍然保留其技术含义：销售进度只计算已经被事实验证的关键节点完成度；而“没有事实，就没有进展”是覆盖整个商业世界模拟的上层哲学。

## 设计原则

### 没有事实，就没有进展

这既是销售规则，也是整个模拟世界的基本原则。主观乐观不会推动真实状态。项目、人物、公司和世界的变化，必须来自事实、行动结果、组织变化、承诺、交付、资金或其他可验证的状态变化。

### 动作不等于成果

发方案、打电话、安排会议、找领导支持，都只是动作。动作可能产生新信息、新风险、关系变化，也可能没有结果，甚至带来负面后果。

### 世界可以复杂，操作必须简单

玩家面对的核心操作始终保持简单：

**移动 / 对话 / 观察 / 判断 / 配置 / 时间推进**

真正的复杂度应该存在于人物、组织、信息、资金、时间和后果中，而不是堆成一墙按钮。

### NPC 是人，不是任务发布器

人物拥有自己的岗位、利益、性格、边界、关系、记忆和变化。职位并不能完全决定一个人的信息价值、影响力和未来价值。

### 世界不会围着玩家转

组织会调整，人会调动，预算会变化，员工会成长，竞争对手会行动，机会也会消失。多年以前建立的关系，也可能重新产生价值。

## 关于 CEO TERMINAL

CEO TERMINAL 尝试把真实的商业、销售和行业经验转化成一个可以玩的模拟世界。

它不是教玩家怎么填销售漏斗。

它想让玩家体验的是：在信息不完整、人物有各自利益、资金有限、结果必须靠自己争取的商业世界里，做出判断并承担后果。
