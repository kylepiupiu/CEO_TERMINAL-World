# Contributing to CEO TERMINAL\n\n**English** | [简体中文](./CONTRIBUTING.zh-CN.md)

Thanks for your interest in the project.

CEO TERMINAL is currently developed through a private production repository. This public repository is used for project information, public builds, feedback, and issue tracking.

## What is welcome

Please use GitHub Issues for:

- reproducible bugs
- Android installation problems
- control and touch-feedback issues
- UI readability problems
- performance problems
- save/load problems
- gameplay feedback based on an actual public build

A useful report should include:

- build version
- device model
- Android version
- what you expected to happen
- what actually happened
- steps to reproduce the problem
- screenshots or screen recordings when useful

## What is not currently accepted

At this stage, the project is not accepting unsolicited pull requests, source-code ports, unofficial forks presented as official versions, or redistributed modified builds.

The production source code and internal design specifications are maintained privately.

## Ideas and feature suggestions

Suggestions are welcome, but submitting an idea does not create ownership, compensation, or implementation obligations. Please keep suggestions focused on player experience rather than requesting private internal rules or unreleased design documents.

## Public builds

Public test builds may be experimental, test-signed, and incompatible with saves from other prototypes. Always read the relevant release notes before installing a new build.
